# Motifs

نقش‌مایه‌ها از خود نشان لوگو ساخته شده‌اند (برداری‌شده از فایل باکیفیت لوگو). SVG با رنگ ثابت. رنگ‌های «flat» همان رنگ‌های دقیق لوگو هستند، بدون گرادیان.

- `neshan-flat.svg`: نشان کامل با رنگ‌های لوگو (طاق #5CC6D0، برگ #00A859، شعله #FFCC29).
- `neshan-ink.svg`: نشان تک‌رنگ با `ink` (#262A4F). مهر و چاپ تک‌رنگ روی زمینهٔ روشن.
- `neshan-white.svg`: نشان تک‌رنگ سفید. روی `ink`، `leaf` یا عکس تیره.
- `taq.svg`: فقط طاق (#5CC6D0). قاب و ماسک تصویر.
- `barg.svg`: فقط برگ با دو قلمش (#00A859).
- `shoale.svg`: فقط شعله (#FFCC29).
