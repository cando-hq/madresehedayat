# Patterns

هر فایل یک واحد بی‌درز است با زمینهٔ شفاف و کدری از پیش تنظیم‌شده. با `background-image` و `background-repeat: repeat` در اندازهٔ واقعی خودش روی زمینهٔ گفته‌شده تکرار کنید. فقط روی سطح‌های بزرگ و خالی.

- `chiraghan-navy.svg` (۱۴۴×۲۰۰): چراغان؛ نشان سفید ۸٪ و شعله‌های `flame`. روی `ink` (#262A4F).
- `neshan-leaf.svg` (۱۴۴×۲۰۰): نشان‌نما؛ `leaf` ۱۲٪. روی `leaf-soft` یا `bg`.
- `neshan-white.svg` (۱۴۴×۲۰۰): نشان‌نما سفید ۱۲٪. روی `leaf` یا `deep`.
- `bargriz-leaf.svg` (۲۲۰×۲۲۰): برگ‌ریز؛ `leaf` ۱۲٪. روی `bg`.
- `bargriz-white.svg` (۲۲۰×۲۲۰): برگ‌ریز سفید ۱۴٪. روی `leaf`.
