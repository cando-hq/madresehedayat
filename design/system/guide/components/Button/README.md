# Button

کنش‌های صفحه؛ در هر نما فقط یک `btn-primary` برای کاری که صفحه برای آن است.

- **چه می‌دهید:** `<button>` (یا `<a>` برای رفتن) با کلاس `btn` و یکی از `btn-primary`، `btn-secondary`، `btn-ghost`، `btn-danger`؛ اندازه با `btn-sm` یا `btn-lg`؛ فقط‌آیکون با `btn-icon` و `aria-label`.
- **وزن از رنگ می‌آید، نه از سایه.** هیچ دکمه‌ای سایه یا درخشش ندارد.
- **متن:** فعل اول، کوتاه: «ادامهٔ یادگیری»، «دریافت کد». بدون علامت تعجب.
- **حذف:** پیش‌فرض خطی است؛ فقط دکمهٔ تأیید نهایی در دیالوگ توپُر می‌شود (`btn-danger btn-solid`).
- **حالت کار:** `disabled` و متن «در حال …»؛ پهنا حفظ شود.
