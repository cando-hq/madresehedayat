# Card

ظرف اصلی محتوا روی `bg`: کارت دوره، کاشی آمار، فهرست و جدول.

- **چه می‌دهید:** عنصر با کلاس `card` و پدینگ `space-6` (موبایل `space-5`). کاشی آمار: `card stat` با `.n` و `.l`.
- **بی‌سایه.** فقط مرز `line`. کارت شناور (منو، دیالوگ) `card-float`.
- **درون کارت:** یک تیتر `h3`، شکاف `space-4`، کنش اصلی پایین و سمت چپ. حداکثر یک دکمهٔ اصلی.
- **نکن:** کارت در کارت؛ نوار رنگی کنارهٔ کارت؛ بیش از یک رنگ تأکید.
