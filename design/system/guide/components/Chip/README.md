# Chip

وضعیت یا ویژگی کوتاه یک چیز؛ رنگ کمکِ متن است، نه جای آن.

- **چه می‌دهید:** `<span class="chip">` با متن و در صورت نیاز آیکون ۱۴px.
- **رنگ‌ها:** `chip` خنثی؛ `chip-leaf` انجام‌شده؛ `chip-flame` منتظر؛ `chip-dome` اطلاعات و زمان؛ `chip-rose` نیاز به اقدام؛ `chip-live` فقط «الان زنده»، با یک نقطهٔ `flame` و بدون زمینه.
- در هر ردیف حداکثر یک چیپ رنگی. متن همیشه وضعیت را می‌گوید.
