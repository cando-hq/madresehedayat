# CourseCover

جلد دوره و مسیر: سطح سادهٔ رنگی در قاب طاق، با برگ لوگو.

- **چه می‌دهید:** ظرف `cover` با یکی از `tint-green`، `tint-dome`، `tint-deep`، `tint-flame`، `tint-rose`؛ برای قاب طاق `cover-arch`. داخلش برگ لوگو (نقش‌مایهٔ `barg`) به رنگ `--t-ink` و عنوان.
- یک رنگ برای هر مسیر؛ دوره‌های یک مسیر یک رنگ.
- **نکن:** عکس، هاله، گرادیان یا بیش از یک نشانه روی جلد.
