# Field

یک ورودی با برچسب، راهنما و پیام خطا.

- **چه می‌دهید:** ظرف `field` شامل `<label for>`، ورودی `input`، و در صورت نیاز `hint` یا `err`.
- **فوکوس** با مرز یک‌پیکسلی `leaf-ink` است، بدون هاله. **خطا** مرز `rose` و پیام `err` که می‌گوید چه کنند.
- شماره و کد: `inputmode` و `dir="ltr"` روی ورودی؛ برچسب راست‌چین می‌ماند. متن ورودی ۱۶px بماند.
- برچسب همیشه دیده شود؛ placeholder جای برچسب نیست.
