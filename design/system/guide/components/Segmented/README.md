# Segmented

جابه‌جایی بین نماهای یک صفحه.

- **زبانهٔ صفحه** (`seg`): خطی، با زیرخط `leaf` زیر گزینهٔ فعال. برای بالای صفحه و پنل‌ها.
- **فیلتر** (`seg seg-pill`): قرصی و فشرده. فقط داخل کارت و بالای فهرست.
- هر گزینه `<button>` است و فعال `aria-pressed="true"` دارد؛ ظرف `role="group"` و `aria-label`.
- ۲ تا ۷ گزینه؛ بیشتر شد در موبایل افقی اسکرول می‌خورد. برای کنش از آن استفاده نکنید.
