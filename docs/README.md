## ۳. طراحی — `design/`

| پوشه | چیست |
|---|---|
| `design/system/` | دیزاین‌سیستم: `tokens.json` و `tokens.css` (رنگ‌ها در دو پوسته، فاصله، گوشه، حرکت، سایه) و `brand/` (لوگوها، نشان، پوستر، مارپیچ). منبع اصلی توکن‌ها در کد `apps/web/src/styles/app.css` است. |
| `design/boards/` | ۶۰ صفحهٔ طراحی (دسکتاپ و موبایل) به‌صورت فایل HTML بوم طراحی |
| `design/generators/` | اسکریپت‌های پایتونی که صفحه‌های بوم را ساختند |
| `design/assets/` | تصویرهای به‌کاررفته در بوم (پوستر، مارپیچ، چرخ) |

## ۴. معماری و تصمیم‌ها — `docs/`

`architecture.md`، `decisions.md`، `design-review.md`، `strategies-handoff.md`.

## ۵. کد و استقرار

- کد: `apps/api` (NestJS + Postgres)، `apps/web` (React)
- استقرار: `DEPLOY.md` در ریشهٔ مخزن
- تغییرات هر نسخه: `CHANGELOG.md`
- تست‌ها: `tests/` (API و رابط) و `tests/e2e/real_e2e.py` (مرورگر روی API واقعی، هر پنج کاربر)
- ساخت نسخهٔ نمایشی: `tools/demo-build/`

## دربارهٔ فونت

فونت رواق با مجوز بنیاد در مخزن است: فایل‌های وب در `apps/web/public/fonts/` و بستهٔ کامل همراه مجوز و شرایط استفاده در `design/system/fonts/`.
