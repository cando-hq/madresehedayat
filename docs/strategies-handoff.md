# تحویل: راهبردهای یادگیری

این سند برای برنامه‌نویسی است که پچ `strategies-full.patch` را روی مخزن اعمال می‌کند.

> **مهم:** این کد در محیطی نوشته شد که به npm دسترسی نداشت. **بک‌اند ساخته و اجرا نشده** و **بررسی نوع (tsc) فرانت هم اجرا نشده**؛ فرانت فقط با esbuild ساخته و در نسخهٔ نمایشی با همهٔ نقش‌ها گشته شده است. پیش از هر چیز `npm run build` را اجرا کنید و خطاهای احتمالی TypeScript را برطرف کنید.

## ۱. اعمال و راه‌اندازی

```bash
git apply strategies-full.patch
npm install
npm run build            # api و web
# روی سرور: کانتینر api هنگام شروع خودش migrate را اجرا می‌کند
docker compose up -d --build
# یا دستی: npm run db:migrate -w apps/api
```

- مایگریشن `0011_growth.sql` دستی نوشته شده و **snapshot ندارد.** اگر بعداً با `drizzle-kit generate` مایگریشن تازه می‌سازید، اول یک snapshot از وضعیت فعلی بگیرید.
- `SCHEDULER=off` زمان‌بند را خاموش می‌کند (مثل قبل).

## ۲. پایگاه داده (`0011_growth`)

| تغییر | کاربرد |
|---|---|
| `courses.skills jsonb` | مهارت‌های هر دوره `[{id,title}]` |
| `lessons.skill_ids text[]` | درس به کدام مهارت‌ها وصل است |
| جدول `weekly_goals` | هدف هفتگی هر کاربر |
| جدول `reviews` | مرورهای با فاصله (روز ۳ و ۱۰ پس از پایان دوره) |
| جدول‌های `cohorts`، `cohort_members` | دورهٔ گروهی هم‌زمان هسته (`notified_station`: آخرین ایستگاهی که اعلانش رفته) |

## ۳. بک‌اند

**فایل‌های تازه:**
- `src/growth/growth.ts`: رشد، مهارت، ریتم هفتگی، مرور، داستان میدان
- `src/cohorts/cohorts.ts`: دورهٔ گروهی هسته

هر دو در `app.module.ts` ثبت شده‌اند.

**مسیرهای تازهٔ API:**

| مسیر | کار |
|---|---|
| `GET me/growth` | مرحلهٔ رشد (دانه، جوانه، نهال، درخت) و شمارها |
| `GET me/skills` | مهارت‌های دوره‌های من |
| `GET me/rhythm`، `PUT me/rhythm` | ریتم هفته و هدف `{lessonsPerWeek: 1..21 \| null}` |
| `GET me/reviews`، `GET reviews/:id`، `POST reviews/:id` | مرور با فاصله |
| `GET stories` | گزارش‌های نمونهٔ منتشرشده (با اجازهٔ کنشگر) |
| `POST lessons/:id/check` | پرسش کوتاه وسط درس |
| `GET cohorts/mine`، `GET cohorts/:id`، `GET cores/:id/cohorts` | دوره‌های گروهی |
| `POST cohorts`، `POST cohorts/:id/join\|leave\|cancel` | ساخت، همراهی، بیرون آمدن، لغو |

**تغییر در فایل‌های موجود:**
- `learning.service.ts`: صفحهٔ دوره مهارت‌ها و `skillIds` را می‌دهد؛ با تمام شدن دوره مرورها زمان‌بندی می‌شوند.
- `lesson-content.ts`: `checks` برای درس متن و ویدیو و صوت؛ پاسخ درستشان به کنشگر فرستاده نمی‌شود.
- `admin.*`: ویرایش مهارت‌ها، وصل کردن درس به مهارت، پرسش کوتاه (حداکثر ۵)؛ هشدار انتشار برای مهارتِ بی‌درس.
- `events.controller.ts` (زمان‌بند): هر ساعت اعلان مرورهایی که وقتشان رسیده، و اعلان بازشدن ایستگاه تازهٔ هر دورهٔ گروهی به همراهانش.

**دسترسی دورهٔ گروهی:** ساختن و لغو را مسئول هسته، امام مسجد هسته، ستاد یا راهیاری انجام می‌دهد که کنشگر را می‌بیند (همان قاعدهٔ `CoresController`). پیشرفت گروه فقط با عدد نشان داده می‌شود و نام کسی دیده نمی‌شود.

## ۴. فرانت

**صفحه‌های تازه:** `/review/:id` (مرور) و `/cohorts/:id` (زمان‌بندی دورهٔ گروهی).

**اجزای تازه:** `components/Growth.tsx` و `lib/growth.ts`.

**بازطراحی‌شده:** خانه (یک قدم بعدی)، مسیر، یادگیری، دوره (مهارت‌ها و مأموریت)، درس (پرسش کوتاه، حالت تمرکز، کارت قدم بعد)، «گواهی‌ها و پیشرفت»، هسته، داشبورد راهیار و داشبورد ستاد.

**نمادهای تازهٔ lucide-react:** Leaf، Sprout، TreeDeciduous، Quote، Maximize2، Minimize2، BookCheck، Sparkles، Compass، CalendarCheck، Target. همه در lucide-react هستند.

## ۵. فهرست آزمون پس از راه‌اندازی

- [ ] با کاربر کنشگر: یک درس را تمام کنید؛ ریتم هفته یک واحد بالا برود.
- [ ] یک دوره را تمام کنید؛ دو ردیف در `reviews` ساخته شود. `due_at` یکی را به گذشته ببرید؛ در یک ساعت اعلان بیاید و صفحهٔ مرور کار کند.
- [ ] در پنل ستاد برای یک دوره مهارت بسازید، به درس‌ها وصل کنید و در صفحهٔ دوره «بلد» شدنش را ببینید.
- [ ] برای یک درس متنی پرسش کوتاه بگذارید؛ پاسخ غلط و درست را امتحان کنید.
- [ ] مسئول هسته یک مسیر گروهی با شروع امروز بسازد؛ در یک ساعت اعلان «شروع شد» به همراهان برسد؛ اعضا اعلان بگیرند، همراه شوند و بیرون بیایند؛ لغو به همراهان خبر بدهد.

## ۶. یادآوری‌های امنیتی (جدا از این پچ)

- اگر nginx یا Caddy جلوی سرور است: درگاه وب در `docker-compose.yml` فقط روی `127.0.0.1` باز شود، و `trust proxy` با چیدمان واقعی پروکسی هماهنگ باشد.
- شماره‌های `BOOTSTRAP_ADMIN_MOBILES` دقیقاً به شکل `09xxxxxxxxx`.
- فونت رواق مجوز شخصی دارد: فقط روی سرور خود مدرسه در `apps/web/public/fonts` گذاشته شود، نه در مخزن عمومی.
