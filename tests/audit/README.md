# گشت کامل صفحه‌ها (پیش از هر تحویل)

با هر نقش (کنشگر، امام، راهیار، برگزارکننده، استاد، ستاد) همهٔ صفحه‌ها را در گوشی (۳۹۰) و دسکتاپ (۱۲۸۰) باز می‌کند،
پیوندها را دنبال می‌کند و ثبت می‌کند: خطای صفحه، API ناموفق، بیرون‌زدگی از صفحه، متن‌های «undefined/null/چیزی درست کار نکرد»، و عکس هر صفحه.

فقط روی سرور آزمایشی؛ هرگز روی سرور اصلی.

```bash
tests/audit/stack.sh fresh          # پایگاه آزمایشی تازه، API، سرورهای ساختگی و vite (محیط آزمون: postgres روی /tmp/pg پورت ۵۴۳۳)
TEST_DB=... API_URL=... python3 tests/run.py      # دادهٔ آزمون
TEST_DB=... python3 tests/audit/setup.py          # نقش برگزارکننده و استاد برای گشت
TEST_DB=... python3 tests/audit/crawl.py          # یا: crawl.py activist rahyar
```

خروجی در `tests/audit/out/` (عکس‌ها و `report.json`).

`tools/text/tovoice.py` متن‌های رابط را از «شما» به «تو» برمی‌گرداند (بعدش جمله‌های التزامی را دستی بخوان).
